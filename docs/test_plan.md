# 秒杀商品管理功能测试方案

## 一、测试环境

### 1.1 软件环境
- Java 17
- Spring Boot 3.2.0
- MySQL 8.0.32 (localhost:3306)
- Redis 6.2.12 (192.168.124.132:6379)
- Node.js 18+

### 1.2 测试前准备
1. 执行数据库初始化脚本 `sql/init_database.sql`
2. 启动Redis服务
3. 启动后端服务 (端口8080)
4. 启动前端服务 (端口5173)

---

## 二、正向测试方案

### 2.1 商品创建测试

#### 测试用例 TC-001: 创建秒杀商品
**测试目的**: 验证能够成功创建秒杀商品并同步到Redis

**前置条件**: 
- 数据库连接正常
- Redis连接正常

**测试步骤**:
1. 访问管理页面 http://localhost:5173/admin
2. 点击"新增商品"按钮
3. 填写商品信息:
   - 商品名称: "测试商品A"
   - 秒杀价格: 99.00
   - 原价: 199.00
   - 库存数量: 100
   - 商品描述: "正向测试商品"
   - 开始时间: 当前时间+1小时
   - 结束时间: 当前时间+25小时
4. 点击"创建"按钮

**预期结果**:
- 页面提示"创建成功"
- 商品列表中显示新创建的商品
- 数据库seckill_product表新增一条记录
- Redis中存在对应的商品缓存 (key: seckill:product:{id})
- Redis中存在对应的库存缓存 (key: seckill:stock:{id})

**验证SQL**:
```sql
SELECT * FROM seckill_product WHERE name = '测试商品A';
```

**验证Redis命令**:
```bash
redis-cli -h 192.168.124.132 -p 6379
GET seckill:product:{id}
GET seckill:stock:{id}
```

## 五、API测试脚本

### 5.1 创建商品
```bash
curl -X POST http://localhost:8080/api/admin/seckill/product \
  -H "Content-Type: application/json" \
  -d '{
    "name": "API测试商品",
    "stock": 100,
    "price": 99.00,
    "originalPrice": 199.00,
    "description": "通过API创建的测试商品",
    "startTime": "2024-01-01T10:00:00",
    "endTime": "2024-01-02T10:00:00"
  }'
```

### 5.2 查询商品列表
```bash
curl "http://localhost:8080/api/admin/seckill/product/page?pageNum=1&pageSize=10"
```

### 5.3 更新商品
```bash
curl -X PUT http://localhost:8080/api/admin/seckill/product \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1,
    "name": "更新后的商品",
    "stock": 200,
    "price": 88.00,
    "startTime": "2024-01-01T10:00:00",
    "endTime": "2024-01-02T10:00:00"
  }'
```

### 5.4 删除商品
```bash
curl -X DELETE http://localhost:8080/api/admin/seckill/product/1
```

### 5.5 同步到Redis
```bash
curl -X POST http://localhost:8080/api/admin/seckill/product/sync/1
```

### 5.6 执行秒杀
```bash
curl -X POST http://localhost:8080/api/seckill/1
```
